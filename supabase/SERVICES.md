# Справочник /services

Миграция: migrations/20261011_service_directory.sql. Примените через SQL Editor к подтверждённому проекту Supabase после проверки его существующей схемы. Она создаёт только две новые таблицы и не меняет чат. Не запускайте reset базы.

На этапе 1 администратор добавляет строки в esx_service_listings через Supabase Table Editor. Обязательны name, city, category, address, service_languages. Названия городов и категорий вводите единообразно: фильтры формируются из опубликованных записей. Языки: ru, uz, zh, vi, en, ko; массивы в редакторе: ["ru","ko"]. Если has_interpreter=true, заполните interpreter_languages. Телефон и website необязательны; сайт начинается с https:// или http://. Сначала сохраните draft, проверьте сведения и смените status на published. Для снятия с публикации выберите archived.

Публичные пользователи и вошедшие в аккаунт видят только published. Запись из браузера запрещена: администратор работает через защищённую панель Supabase. Секретный ключ в браузер не добавлять.

Этап 2: esx_service_owners связывает организацию с auth.users и закрыта RLS. Самостоятельная регистрация пока не включена. Для её запуска нужны подтверждение владельца, политики доступа к своим карточкам, проверка разрешённых полей и модерация изменений через pending. Нельзя разрешать владельцам самостоятельно присваивать published. Контактные данные владельцев хранить отдельно от публичной карточки.

Проверка после применения: draft не виден без авторизации; published виден; insert/update/delete запрещены anon/authenticated; фильтры языка обслуживания и переводчика независимы. Проверить существующий чат. Если публичный ключ возвращает 401, исправить конфигурацию Supabase до проверки данных.

## Администратор сайта
Страница /admin: вход через существующий аккаунт ESX, добавление, редактирование и публикация карточек. Миграция 20261011_service_admin.sql добавляет закрытый список esx_service_admins. Назначение роли выполняется администратором базы по UUID подтверждённого аккаунта. Пользователи не могут назначать себе роль. Удаление карточек не разрешено; для снятия с публикации используйте статус archived. Права распространяются только на справочник услуг, не на чат.
